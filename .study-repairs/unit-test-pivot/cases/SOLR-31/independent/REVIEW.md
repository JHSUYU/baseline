# SOLR-31 source and actor-bound trial review

- **Original test:** Solr 8.11.4 `ForceLeaderTest.testReplicasInLowerTerms` creates three replicas of one shard, lowers follower terms, partitions and stops the old leader, verifies that the shard has no leader, calls `FORCELEADER`, then tests indexing and reads through the new leader.
- **Exact check:** `CollectionsHandler.forceLeaderElection` resolves the requested collection and shard, constructs `ZkShardTerms` using `zkController.getZkClient()`, and throws `SolrException("The shard already has an active leader...")` only when `slice.getLeader()` is nonnull and `ACTIVE` (source lines 1475–1478). If a leader becomes active between the test's pre-request null assertion and this server check, the rejection is protective; a candidate would require clean replay and state review.
- **Physical actor identity:** V2 records the exact `handler.coreContainer.getZkController().getZkClient()` object at target entry and the controller's live node name. The `SolrZkClient` I/O hook records its actual receiver and node. Faults apply only on that same receiver while this target method is on the thread stack, with exact collection/shard source key, allowed znode path, I/O site, role, and ordinal. Offline `-ea` and `-da` smokes reject wrong client, collection, and shard. Two healthy original JUnit seeds passed, reached the guard once with `leader=null`, and each exposed five stable pre-guard bound selectors on seven bound I/O events.
- **Campaign and outcomes:** The 80-effective/max8 checkpoint had final-eight production probe novelty, qualifying the same checkpoint for the 128-effective/max10 extension. All 129 attempts recorded zero exact active-leader throws. The largest JUnit attempt was 99.653 seconds; the two healthy seeds averaged 59.243 seconds.
- **Production coverage:** An independent trace recount agrees with the checkpoint. - **Conclusion:** No exact SOLR-31 active-leader exception or new bug was established in this bounded original-test, bound-client ZooKeeper-I/O fault model.
