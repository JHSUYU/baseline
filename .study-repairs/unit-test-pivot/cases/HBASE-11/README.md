# HBASE-11: expected region state guard

- Target: HBase 2.6.6 `AssignmentManager.preTransitCheck`, the `!regionNode.isInState(expectedStates)` branch at `AssignmentManager.java:760`. Its exact exception is `DoNotRetryRegionException`.
- Original embedded-cluster JUnit: `org.apache.hadoop.hbase.regionserver.TestRegionMove.testDisableAndMove` (two region servers). The original test unassigns a region, attempts to move it, assigns it again, disables the table, then attempts another move.
- Healthy target: four evaluations; both moves intentionally throw the selected B2 exception. The final test's broad `DoNotRetryIOException` catch also accepts this B2 subclass. Thus a B2 exception by itself is not a new bug.
- Execution: the case-local ByteBuddy I/O recorder and JaCoCo production coverage from the simultaneous HBASE-10 original-JUnit campaign are reused as *the same JVM execution*. `independent/mirror.py` independently projects B2 target outcomes, strict ordered faults, post-fault target visits, stable I/O families, and JaCoCo probes into HBASE-11 checkpoints. No GraphChecker skeleton, woven class, or runtime JAR is used. Shared runtime is nonadditive across the cases.
- Source review of a common trial outcome: a fault on a successful `UnassignRegion` or `AssignRegion` RPC **response** causes `HBaseAdmin` to retry the completed operation. The region has already changed state, so B2 rejects the duplicate call as expected. The guard-level throw is an expected retry rejection. The externally visible `Admin` result is tracked separately as an **unconfirmed client-level candidate** in [CANDIDATE.md](CANDIDATE.md); the injected timeout alone is not the candidate.
- Each row of `result.json` records the exact fault sequence, matched/applied counts, target after fault, exception, production coverage, and seconds. The node1 mirror and node0 result publisher run in tmux. The 80-trial/max-8-fault default budget, with conditional 128/max-10 extension, applies to *effective* target-retaining trials; shared execution alone does not guarantee that target-specific budget is met.
