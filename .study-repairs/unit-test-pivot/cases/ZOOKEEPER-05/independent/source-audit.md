# ZOOKEEPER-05 source and oracle audit

- Selected site: `Follower.followLeader()` in ZooKeeper 3.8.7, `Follower.java:98-103`. The bytecode is `LCMP; IFGE` for `newEpoch < self.getAcceptedEpoch()`, followed by the selected `IOException("Error: Epoch of leader is lower")` and `ATHROW` at line 103. The case-local ASM agent records that exact jump and throw. It does not treat another `IOException` as the oracle.
- Original workload: `QuorumRestartTest.testRollingRestart()` starts an embedded three-peer `QuorumUtil(1, 2)` ensemble, then shuts down and restarts peers 1, 2, and 3 in order. After each restart it waits for all peers to reconnect. The JUnit lifecycle is unchanged.
- Protocol path: `Learner.registerWithLeader()` sends a `LearnerInfo` with version `0x10000`, reads the `LEADERINFO` response, and compares its epoch against `self.getAcceptedEpoch()` before returning. A lower epoch throws there first; a higher epoch calls `setAcceptedEpoch(newEpoch)`; equality leaves the value equal. `LearnerHandler.run()` responds with `LEADERINFO` for version `>= 0x10000`. Therefore, without a concurrent accepted-epoch change between that return and the selected comparison, the selected throw arm is unreachable on this protocol path. That is a source-based conditional argument, not a proof that all possible executions are safe.
- Injected failures: case-local ASM hooks at socket-backed quorum packet archive calls and epoch file helper entries throw a selected checked `IOException`. A failed handshake normally aborts that attempt; a failure after the selected comparison cannot make that comparison throw retroactively. This explains why an exception elsewhere or loss of the target does not count as a target bug.
- Production coverage: a separate JaCoCo agent records probe IDs for `org.apache.zookeeper.*` classes. Feedback is admitted only when all planned I/O exceptions match and apply in order and the exact selected guard executes after the last fault. Stable I/O family is `(IO marker, callsite, peer/epoch-file sourceKey)`; the ordinal selects one runtime hit but does not define a new family. Epoch file source keys include the peer and basename, not an absolute file path.
- `LearnerHandler.run():472` reads the initial `FOLLOWERINFO` packet before the handler knows the follower sid. The recorder reports `peer=0` there, which merges concurrent handlers. A mid-campaign identity audit excluded five such trials from strict injection, target, and coverage counts, removed the selector from the remaining queue, and preserved the original checkpoint with its SHA. Other completed trials were retained after recalculating the admitted feedback from their independent run files.
- Methodology provenance: the independent JVM classpath has no GraphChecker or static-skeleton entry. Historical GraphChecker runs are retained only in `legacy-graph-result.json` and are excluded from the current counters.
