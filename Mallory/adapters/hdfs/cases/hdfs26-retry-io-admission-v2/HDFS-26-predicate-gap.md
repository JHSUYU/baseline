# HDFS-26: observed RPC doors do not change the rollback guard

The unchanged `TestDFSRollback#testRollback` passed its healthy MiniDFSCluster run (one JUnit test, no failure). The exact `BlockPoolSliceStorage#doRollback` check was observed on named `hdfs-cluster-3/dn0` and `hdfs-cluster-10/dn0`, with no selected `InconsistentFSStateException`. The frozen causal audit found four root-free, time-respecting pre-target doors, all on the `versionRequest` RPC path. The attached JSON receipt pins the raw run, audit, source files, and event IDs.

`doRollback` reads `prevInfo.layoutVersion` and `prevInfo.CTime` from the DataNode's `previous/VERSION` file, then compares them with the current DataNode layout version and the NameNode `nsInfo.CTime` (`BlockPoolSliceStorage.java:603–626`). The test creates the storage directories and VERSION files before it starts each DataNode (`TestDFSRollback.java:151–209`); its later deliberately invalid rollback scenarios are separate startup cases (`:241–290`).

`BPServiceActor.retrieveNamespaceInfo` catches `IOException` from `bpNamenode.versionRequest()` and retries that same request (`BPServiceActor.java:247–279`). The NameNode handler only returns `namesystem.getNamespaceInfo()` (`NameNodeRpcServer.java:1741–1745`), which constructs its value from the NameNode's FSImage storage under a read lock (`FSNamesystem.java:1876–1902`). Neither observed door writes `previous/VERSION` or changes the NameNode's stored CTime. Thus faulting the DN door or the generic NN RPC door can delay or abort this startup, but the current source/test supplies no path by which that `IOException` changes the selected guard operands while retaining the same DN target.

The healthy graph proves reachability, not a fault mechanism for this guard. No fault pilot or full campaign is justified from these two observed sites. A future attempt needs a source-backed pre-target operation that can affect the local VERSION fields or the NameNode CTime while preserving the selected DN startup; the present run did not establish such a door.
