need a common znode/version and an exact `allKeys` element version. Equal key
IDs or trace order alone do not establish a read-from edge.

The current campaign driver requires an observed healthy `TARGET_CHECK` before
fault trials. A missing healthy target therefore blocks the present run; it
does not prove the original JUnit cannot exercise the target under faults. A
future general target-absent bootstrap can seed from upstream I/O observed in
that same unmodified JUnit and use target reach as feedback. It must preserve
the exact inventory target, let Soot select eligible upstream doors, and keep
target-absent trials distinct from completed target-reaching campaigns.
