# Original 102: target-exception trace audit

The original campaign table separates **target check triggered** from the legacy differential candidate oracle and from **new bug** classification. The trigger criterion is a strict applied fault followed by either an `EXPLICIT_THROW` at the selected target bytecode site with the expected type, or a configured target method/type oracle corroborated by the exact exception message and source branch. A JUnit failure alone is insufficient.
