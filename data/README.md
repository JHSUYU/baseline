# Baseline experiment data

- [`crashfuzz/`](crashfuzz/README.md) contains the completed CrashFuzz-style campaign, including the 102 selected checks, two known-issue controls, result table, and recorded evidence.
- [`mallory/`](mallory/README.md) contains results from the new Mallory-style campaign. Its case identities come from the original 102-check selection; results in the two directories must remain separate.
