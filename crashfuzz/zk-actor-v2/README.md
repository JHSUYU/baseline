# ZooKeeper actor identity V2 (isolated preparation)

This directory is a shared contract for the seven ZooKeeper campaigns whose old JVM probes used `site@@globalOrdinal`. It does **not** modify their checkpoints, agents, raw archives, or `result.json` files. No cluster JUnit has yet run with this V2 library.

`ActorRegistry` binds real receiver objects to a logical client role, ZooKeeper session, peer SID, peer client port, and epoch snapshot directory. Adapter hooks must pass the actual `ClientCnxn`/channel, `NIOServerCnxn` plus its registered `ZooKeeperServer`/session, `QuorumPeer`/file, or `AtomicFileOutputStream.origFile` at the I/O instruction. `Probe.io` injects only after resolution; unresolved actors emit `UNBOUND_IO` and never match a fault plan. The selector is `site@@actor@@resource@@actorLocalOrdinal`. Dynamic socket ports and absolute temporary paths appear only in per-run joins, never in the selector.

The case adapter supplies stable client roles, such as `creatorCloser`, `verifier`, `moveStep3`, or `initialGlobalSession`, at the original test's constructor/callsite. Session IDs are bound to a stable logical session tag after the connect response. Server-side I/O requires a peer SID and a session-to-client join. Until a safe pre-session endpoint join exists, those server events are excluded. `QuorumPeer` supplies its SID and snapshot directory; epoch file calls retain the normalized file name and owner. A peer SID of zero is valid; an *unknown* SID or unbound file is excluded. Two fresh healthy seeds must confirm every planned key before fault trials.

If the workload selects a role such as the currently elected leader, `assignPeerRole(sid, "leader")` gives that peer a stable selector alias while retaining its physical SID in the event fields. A case should use the role alias only when the original test identifies that role at runtime and the two healthy seeds confirm its mapping. The receipt relation still compares the actual peer SIDs, so the alias cannot hide a wrong physical destination.

Adapter callsites can invoke `clientIo(cnxn, sock, remoteClientPort, "read"/"write")` from `ClientCnxnSocketNIO#doIO`, `serverIo(thisCnxn, this.zkServer, this.sessionId, operation)` from `NIOServerCnxn`, and `epochFileIo(thisQuorumPeer, actualFile, operation)` from `QuorumPeer.readLongFromFile`/`writeLongToFile`. For nested atomic writes use `epochFileIo(origFile, operation)`, where `origFile` comes from the actual `AtomicFileOutputStream` receiver. Register the real `ZooKeeperServer` instance with its owning quorum SID; do not use the base `ZooKeeperServer.getServerId()` as an unconditional peer mapping, because that base method returns zero. Register a peer with client port `0` if a file-only adapter does not yet know its client port; socket I/O to that peer then remains unbound until the port mapping is supplied.

`Probe.targetGuard` emits the selected check's logical target separately. `receipt_validator.py` verifies the ordered applied plan, target after final fault, and a per-fault relation. Relations include `same_peer`, `client_to_peer`, `epoch_file_owner`, `same_session`, and `counterparty_to_peer`; they deliberately allow cross-peer communication faults when the actual counterparty is the target peer. A new leader is accepted only if the adapter records its current role/peer and the case contract allows that transition. Thread names are diagnostic only.

Run the isolated, no-JUnit smoke with `python3 offline_smoke.py`. It compiles the Java registry and probe using the local JDK, exercises two client handles and two peer-owned epoch files at the same callsites, checks that only fully bound keys inject, and verifies a deliberately wrong target is rejected. This is a contract test, not evidence that the seven campaigns have been rerun.

The per-case minimum actor keys and fail-closed exclusions are in [the identity audit](../audits/zookeeper-terminal-actor-identity-2026-10-07.md). Follow-up case adapters should first add passive actor-aware healthy probes, then use a separate V2 queue/checkpoint and actor-aware effective-trial denominator. Preserve old callsite-level evidence without adding it to the V2 denominator.
