## Target throws and source conclusion

Exact target throws occurred in trials **038, 048, 064, 247, 252, and 298**. The [V4 five-throw review](actor-v2/v4-five-target-throw-source-review.md) and [trial-298 review](actor-v2/v5-trial298-source-review.md) checked each strict fault sequence, the original JUnit log, and the Solr source. In all six, the client timed out during the initial collection `CREATE`; the original test logged its ending before `@AfterClass` cluster shutdown closed the selected core. Registration resumed on that closed core, producing the target exception. None reached the test's later `ADDREPLICA` section. The six receipts are one teardown-race candidate family, **not six independent coordination bugs**. The initial CREATE timeout could merit a separate exact-replay recovery study; these artifacts do not establish novelty or a failure of the selected check while the test cluster remains active. `new_bug=false`, `novelty=pending` for that timeout question.
