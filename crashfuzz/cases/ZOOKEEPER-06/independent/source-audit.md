# ZOOKEEPER-06 source and oracle audit

- Selected site: ZooKeeper 3.8.7 `Leader.waitForEpochAck(long, StateSummary)` at `Leader.java:1471-1475`. The selected bytecode evaluates `StateSummary.isMoreRecentThan(leaderStateSummary)`, then uses `IFEQ` to skip the fatal arm; the fatal arm creates an `IOException` beginning `Follower is ahead of the leader` and executes `ATHROW` on line 1475. The case-local ASM probe records that exact jump and throw.
- The original `QuorumRestartTest.testRollingRestart()` starts an embedded three-peer quorum, then restarts one peer at a time and waits for reconnection. The independent healthy run reaches the exact selected guard four times, all on its normal arm. The JUnit passes.
- `StateSummary.isMoreRecentThan` orders `(currentEpoch, lastZxid)` lexicographically. In `Leader.lead()`, the leader summary is initialized from `self.getCurrentEpoch()` and the loaded database's `getLastProcessedZxid()`. On the version-`0x10000` handshake, `LearnerHandler.run()` reads an `ACKEPOCH` packet and constructs the follower summary from its payload epoch and packet zxid before calling `waitForEpochAck`. The selected exception is a protective rejection if that summary exceeds the leader's. Its occurrence after a fault would be an oracle candidate requiring a concrete recovery-state and workload review, not automatic proof of a new bug.
- Checked-I/O selectors use an actual runtime callsite, peer/epoch-file source key, and occurrence ordinal. Full plans must match and apply in order; the exact selected guard must run after the final injection for coverage or I/O novelty to be admitted. Epoch file source keys distinguish peer and basename, not absolute paths. The pre-FOLLOWERINFO `LearnerHandler` read uses sid zero and is excluded from candidate selection because it cannot identify a specific handler.
- A case-local ASM agent records the selected bytecode outcome and direct quorum/epoch-file I/O. JaCoCo independently records production probe coverage. The JUnit classpath excludes GraphChecker and precomputed region skeletons. Historical GraphChecker runs in this case remain legacy evidence only.
