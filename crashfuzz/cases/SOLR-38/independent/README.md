**Disposition: `no_usable_cluster_test` for the audited original methods and transient ZooKeeper exception model.** The selected guard is real and frequently reached, but neither original method places an update while local and cluster leader views disagree. This is a target-relevant workload gap, not proof that the branch is bug-free and not source exclusion. All 80 campaign trials, the calibration, exact selectors, run times, and coverage evidence remain archived. A future test needs an original cluster operation or fault that overlaps update forwarding with leader-state divergence; any target exception would require replay and source review.
